Prepared explanation — not a fresh AI response. The project’s saved AI output contained some inaccurate service-to-vulnerability descriptions. This demo uses a reviewed, educational explanation of the recorded findings. A CVE match is not proof of compromise.

SUMMARY · What did the scan find?

The saved Nmap scan recorded 23 open services on the Metasploitable laboratory VM. These include FTP, SSH, HTTP, DNS, database services and other older network services. The saved vulnerability analysis linked some detected service versions to 115 possible CVE matches. Many of these are version-based candidates and still require manual checking.

The clearest demonstration case is vsFTPd 2.3.4 on port 21. It is associated with CVE-2011-2523, a backdoored software distribution that can allow unauthorised command execution. The team’s separate controlled laboratory test recorded successful verification of the id command.

PRIORITY · Which findings matter most?

Priority 1: vsFTPd 2.3.4 / CVE-2011-2523 (CVSS 9.8 in saved data). This is the only case in the prototype’s approved controlled-test catalogue. The recorded lab test provides stronger evidence than the scanner banner alone.

Other findings: The saved analysis also includes possible issues linked to OpenSSH, Apache HTTP Server, ISC BIND, PostgreSQL and ProFTPD. Their CVE identifiers and scores appear in the table above, but these are not confirmed exploits in the current project. A high score does not automatically mean a particular host is exploitable.

Open a row in the findings table for its recorded CVE description. In real assessments, check the exact software build, configuration and advisory before reporting a confirmed vulnerability.

SAFETY · What happens after the AI explanation?

  1. AI explains only. It cannot invent a test and run it.
  2. Python checks a fixed catalogue. In this project, vsFTPd 2.3.4 / CVE-2011-2523 is the supported controlled verification case.
  3. Human approval is required. The user must explicitly approve the permitted test.
  4. Metasploit performs the controlled check in the real lab. This website only plays back the recorded evidence after you approve the simulation.
  5. No approved match means no test. Other findings remain informational.

MITIGATION · What should the owner do?

  • Remove and replace compromised vsFTPd 2.3.4 builds. Install a trusted, supported release from a reliable source and restrict FTP exposure.
  • Review other outdated services. Check the relevant vendor advisories and patch unsupported or affected versions after validating each finding.
  • Reduce unnecessary services. Disable services not needed and restrict access using network controls.
  • Retest after remediation. Verify that the affected software and configurations have been corrected.
